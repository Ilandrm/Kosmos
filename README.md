## 🚀 Présentation

Kosmos est une suite de mini-jeux sur le thème de l'espace, au design futuriste, mature et professionnel. Chaque mini-jeu propose une expérience unique durant au maximum 30 secondes.

## 🎮 Mini-jeux

### 1. Évitement d'Astéroïdes
Déplacez votre vaisseau spatial horizontalement pour éviter les astéroïdes et collectez des étoiles filantes pour améliorer votre score !

- **Contrôles** : Flèches gauche/droite ou A/D pour déplacer le vaisseau
- **Objectif** : Survivre le plus longtemps possible et obtenir le meilleur score
- **Bonus** : Les étoiles filantes donnent 50 points chacune
- **Durée** : 30 secondes

## 🛠️ Technologies

- **Frontend** : Vue.js 3 avec TypeScript
- **Rendu** : Canvas 2D
- **Gestion d'état** : Pinia
- **Routage** : Vue Router
- **Build Tool** : Vite

## 📋 Prérequis

- Node.js (v16 ou supérieur)
- NPM ou Yarn

## 🚀 Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/yourusername/kosmos.git
   cd kosmos
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Démarrez le serveur de développement :
   ```bash
   npm run dev
   ```

4. Ouvrez votre navigateur à l'adresse indiquée (généralement `http://localhost:5173`)

## 🏗️ Build

Pour créer une version de production :

```bash
npm run build
```

## 🧪 Tests

```bash
npm run test
```
